# Mock data (v2)

Every figure the portal shows lives in this folder. The v2 files are generated by
`node scripts/generateData.mjs` (or `npm run data`) from a fixed seed, so reruns give identical output
and hand edits are overwritten. Status: **planned** — pass 2 of RUNBOOK.md writes them.

| File | Status | What it will hold |
| --- | --- | --- |
| `areas.json` | planned | The 100 covered areas (CLAUDE.md §6): polygon, type, group, bundle, county, homes, TIV, premium, real fire history. |
| `homes.json` | planned | ~49,500 insured homes on jittered street grids inside the homes areas: footprint, invented address, TIV, premium, construction, roof, defensible space. |
| `assets.json` | planned | Utility assets: lines and pipelines with poles every 90 m, refinery, tank-farm and wind footprints, substations, WMP status. |
| `ranches.json` | planned | Rangeland policies: acres, pastures, last burn, cattle, fencing, headquarters, TIV. |
| `fires.json` | planned | The ten dated fires (§7): ignition zone and prior, window, fuel state, recipe, P90/P50/P25 perimeters per step, bands, loss range, homes and assets in path. |
| `watchlist.json` | planned | Five areas below the 90% dating threshold, with probability and window. |
| `plans.json` | planned | Intervention plan per fire (§11): verdict, actions, payers, pPrevent, loss if the plan holds or fails. |
| `negotiations.json` | planned | Agent negotiations (§12): stage, counterparty, entries, ledger — ten current plus four from last month. |
| `bundles.json` | planned | Premium Intelligence bundles (§15): rates, adequacy, 2027 recommendation, science panel. |
| `historical.json` | planned | Twelve 2025–26 fires with what PRIMER and seven named models said, plus the ruled-out table (§16). |
| `models.json` | planned | PRIMER and the seven named models: outputs, resolution, horizon, fuel treatment, hit rate, Brier. |
| `seasonStats.json` | planned | Headline tiles for Historical Accuracy. |
| `portfolio.json` | stub | The two portfolios; pass 2 adds totals, AAL, OEP, TVaR, EP curve, concentrations and data quality. |
| `meta.json` | in use | Forecast issue stamp and the signed-in user. |

The v1 data (six areas, six fires) sits in `v1/` and feeds the screens not yet rebuilt; it is deleted in pass 12.
