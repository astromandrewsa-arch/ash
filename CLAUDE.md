This file is the source of truth for the v2 overhaul of the Pyrome click-through demo. Read it in full before every step. ## 0. How to work in this repo (autonomy rules)

- You are running unattended overnight in a cloud session. Never ask the user a question. When the spec leaves something open, decide, write one line in DECISIONS.md (date, what, why), and carry on.
- Work on branch `v2-overhaul` (create it from the default branch if it does not exist; if the session gave you another branch, work there and say so in DECISIONS.md). After every pass: `npm run build` must succeed, the smoke test (section 21) must pass with zero console errors, then `git add -A && git commit -m "pass N: <summary>" && git push -u origin HEAD`. - Read PROGRESS.md first. Do only the pass you were asked to do in the prompt, unless the prompt says otherwise. If an earlier pass is unticked, do that one instead and say so in your final message.

## 1. Purpose and product rules

- A click-through demo of the Pyrome insurer portal for a five-minute walk-through with an insurer. Mock data, no backend, no login, no real model. It must look and behave like the finished product.
- The model is PRIMER. It measures live and dead fuel moisture on the ground and puts a date on a fire. The add-on is the Intervention Plan, run by a dedicated Pyrome agent who negotiates with the state, the county, the utility and the landowner.
- Three principles on every screen: ignition is a zone, not a dot; spread is a band, not a line; loss is a range, not a number. Every figure carries the vocabulary an insurer's model committee uses (section 19).
- Forecast issue date: 29 Sep 2026, 06:00 CT. All dates 2026. Money in USD. Book: "Demo Carrier — Texas HO book" plus a second portfolio "Demo Carrier — Texas + Oklahoma".

Every file is an array unless stated. IDs are short strings. Coordinates are `[lat, lng]`.

## 7. The ten dated fires

One forecast definition, shown once in Help and on the Map panel: **PRIMER dates a hectare on the first day its accumulated fire probability inside a window of 14 days or less reaches 90%.** Each fire shows its own call date, window, probability and narrowing. Header format everywhere: **Called 29 Sep · Burns 15–20 Oct · 90%**. Probability is re-scored every six hours; a dated fire can drift after the call and drops to the watchlist below 80%.

Ignition zones: Block 300–600 ha, Zone 1,000–1,500 ha, Sector 4,000–12,000 ha. Draw as an orange boundary with a heat layer of the ignition prior inside (hottest along power lines, roads, ranch tracks).

Spread generator (`scripts/lib/spread.mjs`): Huygens vertex expansion on a 72-vertex polygon. Per time step, each vertex moves by the ellipse velocity for its bearing relative to the wind: head rate R, flank rate R × f, back rate R × b, where for length-to-breadth ratio LB: HB = (LB + √(LB²−1)) / (LB − √(LB²−1)), b = 1/HB, f = 1/LB. Recipes list segments with wind direction, wind speed, head rate and LB. Apply: night slowdown (×0.3 between 21:00 and 07:00 local), a wind-shift event (freeze the old polygon, start expansion from every vertex of the newly exposed flank with the new wind), fingers (vertices within ±10° of a finger bearing move ×1.6), spotting (add satellite ignitions at the given distance downwind that grow and merge), barriers (lakes, rivers, highways as polylines buffered 60 m: difference the perimeter; highways are only 70% effective, i.e. crossed after a 2 h delay), islands (subtract fixed patches). Bands: P90 = R × 0.8 and LB × 0.9; P50 = base; P25 = R × 1.25 with spotting on. Steps at hours 1, 4, 8, 12, 24, 36, 48, then each day to the window end. Sanity: area grows about with t² under steady wind; PH-01 reaches roughly 2,000 ha at 1 h and 120,000 ha at 8 h.

## 8. Loss and insurance figures on a fire

- Bands: P90 (burns in at least 90% of ensemble runs, the core), P50 (expected), P25 (tail if nothing intervenes). Each band: homes, assets, exposed TIV, mean damage ratio (0.45–0.72 by fuel and construction: Frame 0.72, Masonry 0.55, Steel 0.45; utilities 0.15–0.35; rangeland 0.08), loss.
- Loss shown as lower / point / upper = P90 / P50 / P25 loss. Ground-up vs gross toggle: gross applies a 2% deductible and a $1.2M per-location limit. Return period of the point loss on the book's EP curve, stated as "a 1-in-N event for this book".
- Inclusions line: "Includes demand surge 18%, debris removal 5%, ALE. Excludes smoke, urban conflagration beyond the band." Analogue event named.
- 30-day expected loss for the alert card = Σ probability × point loss over visible fires.
