# RUNBOOK — the twelve passes

Each pass is one step of the cloud session, in order. The prompt for pass N is `runbook/pass-NN.md`; every prompt starts with the same header and ends with the same trailer. To run a single pass by hand, paste the file's contents into the cloud session.
